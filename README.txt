HOW TO UPDATE YOUR EXISTING GITHUB PAGES WEBSITE
1. Open your repository: Sile-dev / Sile-advertising-website.
2. Upload all files in this folder into the repository's ROOT (not inside another folder).
3. Choose to replace the old index.html, styles.css and script.js when GitHub asks.
4. Add the six category HTML files.
5. Commit the changes. Your existing GitHub Pages address should update automatically.

IMPORTANT
- Keep all these files together in the repository root.
- The portfolio examples are fictional concepts, not claimed client work.
- WhatsApp buttons use the SILE contact number supplied for the website.
- The contact email is currently a placeholder (hello@sileadvertising.com); change it to your real business email before promoting it.
- No build step or installation is required. This is a static HTML/CSS/JS website.
